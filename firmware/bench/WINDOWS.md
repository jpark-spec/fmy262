# OPL3 벤치를 Windows PC에서 FM-1용으로 빌드하기

코드는 맥에서 고치고, Windows PC에서는 빌드와 굽기만 한다.

## 0. 굽기 전에 (꼭)

- FM-1 Workbench 문서에서 **원래 펌웨어로 되돌리는 방법**(복구 모드, 원래 펌웨어 파일)을 먼저 확인한다.
- 원래 펌웨어 파일을 따로 보관한다.

## 1. Windows PC 준비

1. FM-1 Workbench(AC79 SDK)를 받아서 문서에 적힌 대로 설치한다(툴체인, 빌드 도구, 굽기 도구).
2. SDK에 들어 있는 **예제 펌웨어를 수정 없이 한 번 빌드해서 구워 본다.** 여기까지 되면 PC 환경은 완성이다.
3. 그때 예제의 로그(printf)를 어디서 보는지(UART, USB 시리얼) 확인한다.

## 2. 이 폴더 옮기기

이 저장소 전체를 PC로 복사한다(USB 메모리, 공유 폴더, git 등). 필요한 파일:

- `firmware/bench/fm1_glue.c`, `firmware/bench/opl3_bench.c`
- `opl3/opl3.c`, `opl3/opl3.h`

## 3. 예제 프로젝트에 붙이기

1. 예제 프로젝트의 소스 목록에 `fm1_glue.c`와 `opl3/opl3.c`를 추가한다. 파일 목록은 Makefile이나 프로젝트 파일에 있다. `opl3_bench.c`는 추가하지 않는다.
2. include 경로에 `opl3` 폴더를 추가한다.
3. `fm1_glue.c`에서 `FILL` 두 곳을 채운다.
   - `SDK_TIME_NOW`: SDK의 시간 함수(ms나 us)로 바꾼다.
   - 앱 시작 코드에서 `fm1_opl3_bench()`를 한 번 부른다.
4. 빌드하고 구운 뒤 로그를 본다.

## 4. 결과 읽기

```
OPL3 18ch: 10 s of audio in 2160000 us -> 21.6% of one core
```

- 마지막 %가 코어 하나에서 차지하는 부하다. 50%를 넘으면 더 가벼운 OPL 코어로 바꾸는 걸 검토한다(CLAUDE.md 실기 이식 계획 1번).
- 숫자가 비정상(0이거나 매우 큼)이면 `BENCH_TICK_US`가 시간 함수 단위(ms=1000, us=1)와 맞는지 본다.
- 결과 로그를 그대로 맥 쪽 대화에 붙여 넣으면 된다.

## 막히면

빌드 오류 메시지나 예제 프로젝트의 폴더 구조(파일 목록)를 그대로 가져온다. 특히 SDK 폴더는 맥에도 복사해 두면 시간 함수와 시작 코드를 맥에서 찾아 `FILL`을 미리 채울 수 있다.

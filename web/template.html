FMY262 — FM-1 OPL3 트래커

FM-1 실기 조작부를 흉내 낸 브라우저 프로토타입입니다. 소리는 FM-1 펌웨어와 같은 OPL3 에뮬레이터 DBOPL(44.1kHz)로 내고, 18채널 · 64행 패턴으로 곡을 짭니다.

화면을 한 번 누르면 소리가 켜집니다. 조작부는 FM-1 매뉴얼의 구성(왼쪽 MASTER·인코더 3개, 오른쪽 노브 4개, 버튼 12개, 27건반)을 따랐고, 각 조작부의 트래커 기능은 제가 정한 배정입니다. 처음 열리는 곡은 예시로 만든 데모 곡입니다.

악기 편집 (ENV)

Adlib Tracker의 악기 편집을 4페이지로 나눴습니다. SEL로 고른 오퍼레이터(OP1 모듈레이터 / OP2 캐리어)에 노브가 적용되고, 화면에는 두 오퍼레이터가 나란히 보입니다.

페이지노브 1노브 2노브 3노브 4
1 VOICE악기 번호파형 8종AM · VIB · EG · KSR 고르기, HOME과 함께 켜기/끄기주파수 배수
2 ADSR어택디케이서스테인 레벨릴리스
3 OUTPUT출력 레벨피드백파인 튠 (±99센트)패닝 L·C·R
4 SCALE키 스케일 레벨연결 방식 FM/ADD/4OP 네 가지(ALGORITHM과 같음)––

악기 화면에서 PRESETS를 돌리면 프리셋 창이 열립니다. PRESETS로 고르고(노브 1은 분류 이동), 고를 때마다 미리 듣기가 울립니다. SEL을 누르면 지금 편집 중인 악기 번호에 불러오고, ENV를 누르면 취소합니다. 팩토리 프리셋 34개는 이 프로토타입용으로 직접 만든 음색입니다.

악기 화면에서 SAVE를 누르면 이름 입력 창이 열립니다. 건반 하나에 글자 3개씩 배정돼 있어서(F3=ABC, G3=DEF …), 같은 건반을 1초 안에 다시 누르면 다음 글자로 바뀝니다. 컴퓨터 키보드로 바로 쳐도 됩니다. EDIT는 한 글자 지우기, SAVE를 한 번 더 누르면 그 이름으로 악기 이름이 바뀌고 음색이 USER 분류의 새 슬롯(U01–U32)에 저장되며, 프리셋 창 맨 끝에 나타납니다. 유저 프리셋은 곡과 따로 이 브라우저에 보관되므로 다른 곡에서도 불러올 수 있습니다. 지우려면 프리셋 창에서 그 슬롯을 고르고 EDIT를 두 번 누르세요.

ADSR은 오른쪽으로 돌리면 길어지거나 커지도록 맞췄고, 칩 값 대신 대략의 시간(ms)으로 보여줍니다.

곡 파일 (GLO)

곡은 Adlib Tracker II의 .A2M 형식(v11, 18채널 OPL3)으로 슬롯 4개 중 하나에 저장합니다. 악기·매크로 테이블·패턴·순서가 한 파일에 들어가고, AT2보다 정밀한 값(파인 튠, 비브라토 깊이, 음수 아르페지오)은 파일의 예비 영역에 함께 넣어 다시 불러와도 그대로 돌아옵니다. SAVE를 누르면 FILE 화면이 열리고 노브 1 또는 SELECT로 슬롯을 고른 뒤 SAVE를 누릅니다. 빈 슬롯이면 곡 이름 창이 열리고(악기 이름과 같은 3글자 입력), 지금 곡이 저장된 슬롯이고 바뀐 것이 없으면 바로 저장됩니다. 곡이 바뀌었거나 다른 곡이 든 슬롯이면 덮어쓰기 경고가 뜨고, SAVE를 한 번 더 눌러야 저장됩니다. 이름은 빈 슬롯에 처음 저장할 때만 정하고, 나중에 바꾸려면 EDIT(이름 바꾸기)를 씁니다. 삭제는 OCT−를 두 번, SEL은 불러오기, FX는 내보내기, ENV는 USB 가져오기이고 그 밖의 버튼은 모두 취소입니다.

FILE 화면에서 FX는 지금 곡을 내보내기(zip 안의 .A2M), ENV는 USB 가져오기 대기 상태입니다. 대기 중에는 아래 업데이트 페이지에서 보낸 파일만 받습니다. AT2 v9–v14 곡과 Reality AdLib Tracker(.RAD v1.0·v2.1) 곡을 읽을 수 있고(RAD의 리프는 패턴에 펼쳐 넣음), 그보다 오래된 형식은 AT2에서 한 번 다시 저장해야 합니다.
